# 📚 `libft` Test

*by Matthias Sars, <msars@student.42berlin.de>*

## Description
Simple test programs for the project 'Libft' from the 42 core curriculum (version 19.2). The Norm and compilation behaviour are not checked. In part 1, the functions are checked against the libc functions.

## Instructions
My own Libft repo is contained as a submodule. To run it with other Libft repos, make sure your `libft` directory is in this directory. Compile with `make` and run with `./test_part1`, `./test_part2`, or `./test_part3`.

This tester also cases of which I'm not sure they are relevant, for example `ft_lstadd_front(NULL, lst)` . If you get segmentation faults and you don't want to check for these cases, feel free to change the `.c` files.

No guarantees; also perform your own tests!
